## About This Repository

This repository is my personal Machine Learning workspace and project portfolio. It includes:

- **Classification:** Predicting categories using datasets and classification algorithms.
- **Regression:** Predicting numerical values using linear models and neural networks.
- **Neural Networks:** Building and training models with TensorFlow and Keras.
- **Data Analysis:** Exploring datasets, preprocessing data, and visualizing results.
- **Experiments:** Practicing ML concepts and testing different approaches.
